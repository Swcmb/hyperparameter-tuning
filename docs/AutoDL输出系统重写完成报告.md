## 使用示例

### 基本使用

```python
from unified_log_manager import init_global_log_manager

# 初始化全局日志管理器
log_manager = init_global_log_manager("my_experiment")

# 使用结构化标签输出
log_manager.log_with_tag(logging.INFO, "TRAINING", "开始训练", "MyComponent")

# 结构化数据输出
log_manager.log_structured(logging.INFO, "METRICS", {
    "accuracy": 0.95,
    "loss": 0.05,
    "epoch": 10
}, "MyComponent")

# 进度跟踪
log_manager.log_progress("TRAINING", 50, 100, "训练进度", loss=0.1)
```

### 集成到现有代码
