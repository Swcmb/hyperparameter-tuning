## 📚 文档导航

**新用户建议阅读顺序：**
1. 先阅读 `05-项目文档/项目总结.md` 了解项目概况
2. 阅读 `05-项目文档/AutoDL使用说明.md` 学习如何使用系统
3. 根据需要查阅 `01-核心组件说明` 中的组件文档

**开发者建议阅读顺序：**
1. 阅读 `05-项目文档/API文档.md` 了解系统API
2. 阅读 `01-核心组件说明` 中的核心组件文档
3. 阅读 `04-系统修复和测试` 了解测试和验证

**故障排查：**
- 参数问题：查看 `03-MoCo参数相关` 和 `04-系统修复和测试`
- 输出问题：查看 `02-输出系统相关`
