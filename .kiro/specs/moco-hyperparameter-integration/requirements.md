# 需求文档

## 介绍

本功能旨在为现有的贝叶斯优化器系统添加MoCo（Momentum Contrast）对比学习相关的超参数支持。系统当前已支持基本的MoCo参数（moco_K、moco_queue、moco_momentum、moco_t、proj_dim等），但需要扩展支持更多MoCo变体和高级配置参数，以便进行更全面的超参数优化。

**配置方式**: 基于系统设计决策，所有MoCo参数仅通过JSON配置文件进行配置，不支持命令行参数。这种方式提供了更好的配置管理、版本控制和可重现性。

## 术语表

- **BayesianOptimizer**: 贝叶斯优化器，主要的优化协调器类
- **ParameterSpace**: 参数空间管理器，管理所有可优化参数的定义、验证和采样
- **MoCo**: Momentum Contrast，动量对比学习方法
- **DoubleTau**: MoCo的双温度变体，使用不同的温度系数处理正负样本
- **InfoNCE**: 信息噪声对比估计损失函数
- **Queue_Warmup**: 队列预热机制，在训练初期使用批内负样本

## 需求

### 需求 1: 扩展MoCo参数支持

**用户故事:** 作为研究人员，我希望能够优化更多MoCo相关的超参数，以便找到最佳的对比学习配置。

#### 验收标准

1. WHEN 系统解析命令行参数 THEN 系统应该支持以下新的MoCo参数：
   - moco_m: MoCo动量更新系数，默认0.999
   - moco_T: MoCo基础温度系数，默认0.2  
   - moco_tau1: DoubleTau MoCo正样本温度系数，默认0.2
   - moco_tau2: DoubleTau MoCo负样本温度系数，默认0.3
   - enable_view_0: 是否启用MoCo第0视图，默认true

2. WHEN 添加新参数时 THEN 系统应该避免与现有参数重复定义

3. WHEN 参数被添加到参数空间时 THEN 系统应该正确设置参数类型、范围和约束条件

### 需求 2: 参数验证和约束

**用户故事:** 作为系统管理员，我希望系统能够验证MoCo参数的合理性，确保参数组合的有效性。

#### 验收标准

1. WHEN 验证MoCo参数时 THEN 系统应该确保动量系数在合理范围内（0.9-0.9999）

2. WHEN 验证温度参数时 THEN 系统应该确保温度系数为正值且在合理范围内（0.01-1.0）

3. WHEN 使用DoubleTau模式时 THEN 系统应该确保tau1和tau2都为正值且tau2 >= tau1

4. WHEN 队列大小参数存在时 THEN 系统应该确保moco_K和moco_queue参数一致性

### 需求 3: 参数空间集成

**用户故事:** 作为开发者，我希望新的MoCo参数能够无缝集成到现有的贝叶斯优化参数空间中。

#### 验收标准

1. WHEN 创建默认参数空间时 THEN 系统应该包含所有MoCo相关参数的定义

2. WHEN 进行参数采样时 THEN 系统应该能够生成满足约束条件的MoCo参数组合

3. WHEN 参数被修复时 THEN 系统应该能够自动修复违反MoCo约束的参数

### 需求 4: 贝叶斯优化支持

**用户故事:** 作为研究人员，我希望贝叶斯优化器能够优化新添加的MoCo参数。

#### 验收标准

1. WHEN 贝叶斯优化器建议参数时 THEN 系统应该能够建议有效的MoCo参数组合

2. WHEN 更新高斯过程模型时 THEN 系统应该正确处理MoCo参数的特征编码

3. WHEN 评估参数组合时 THEN 系统应该将MoCo参数正确传递给任务评估器

### 需求 5: 配置转换支持

**用户故事:** 作为系统用户，我希望优化得到的MoCo参数能够正确转换为实验配置格式。

#### 验收标准

1. WHEN 转换优化参数为实验配置时 THEN 系统应该正确映射所有MoCo参数

2. WHEN 参数名称存在别名时 THEN 系统应该处理参数名称的映射关系

3. WHEN 验证实验配置时 THEN 系统应该检查MoCo参数的完整性和一致性

### 需求 6: 向后兼容性

**用户故事:** 作为现有用户，我希望新功能不会破坏现有的优化流程。

#### 验收标准

1. WHEN 使用现有配置时 THEN 系统应该继续正常工作而不需要修改

2. WHEN 新参数未指定时 THEN 系统应该使用合理的默认值

3. WHEN 加载历史优化结果时 THEN 系统应该能够处理缺少新参数的历史数据

### 需求 7: 配置文件参数支持

**用户故事:** 作为系统用户，我希望能够通过配置文件指定MoCo配置，而不是通过命令行参数。

#### 验收标准

1. WHEN 加载配置文件时 THEN 系统应该正确解析所有MoCo参数

2. WHEN 参数类型转换时 THEN 系统应该正确处理布尔值、浮点数和整数类型

3. WHEN 参数验证失败时 THEN 系统应该提供清晰的错误信息

4. WHEN 用户尝试通过命令行设置MoCo参数时 THEN 系统应该提示用户使用配置文件

### 需求 8: 多目标优化支持

**用户故事:** 作为研究人员，我希望在多目标优化中也能使用MoCo参数。

#### 验收标准

1. WHEN 进行多目标优化时 THEN 系统应该正确处理MoCo参数的帕累托前沿计算

2. WHEN 计算目标函数值时 THEN 系统应该考虑MoCo参数对不同目标的影响

3. WHEN 生成帕累托最优解时 THEN 系统应该包含相应的MoCo参数配置
